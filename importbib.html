Importer des bibliothèques Python

Une bibliothèque Python contient un ensemble de fonctions et parfois de variables. Lorsque l’on importe une bibliothèque simplement :

import turtle

Ces objets sont accessibles par la notation pointée bibliothèque.var ou bibliothèque.fonction(..) :

turtle.forward(10)
turtle.left(45)

On peut utiliser directement les fonctions de la bibliothèque telles que forward et left en les important explicitement :

from turtle import forward, left
forward(10)
left(45)

On peut aussi importer tous les noms de la bibliothèque avec l’instruction suivante :

from turtle import *

Cependant cette forme n’est pas recommandée, même si nous l’avons beaucoup utilisée jusqu’à présent, par simplicité. En effet, on ne sait pas quels noms sont importés, et on risque de créer des conflits avec les noms utilisés dans le programme :

pi = 0.5  # probabilité de l'événement
from math import *
print(pi)  # affiche 3.141592653589793 car math définit aussi "pi"

Enfin, on peut renommer les bibliothèques et les objets importés, ce qui est utile en cas de conflit de nom ou pour utiliser des noms plus courts ou plus appropriés :

import turtle as t
t.forward(10)
t.left(45)

from turtle import forward as avance, left as gauche
avance(10)
gauche(45)

Trouver, installer et utiliser des bibliothèques

De nombreuses bibliothèques sont pré-installées avec Python. On peut aussi trouver des bibliothèques Python en effectuant une recherche sur le Web. Deux sites très utilisés ont chacun leur propre moteur de recherche : PyPI (Python Package Index, pypi.org) et Anaconda (anaconda.org).

Les bibliothèques sont en général documentées sur le Web. Elles sont également documentées par les docstrings de leurs fonctions. Cette documentation est accessible depuis une session Python interactive avec la fonction help :

>>> import turtle as t
>>> help(t.forward)
Help on function forward in module turtle:
forward(distance)
    Move the turtle forward by the specified distance
