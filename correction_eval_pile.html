Asie - 2024 - sujet 2 - Correction

Exercice 1 (10 points)

1. Analyse de l’expression

L’expression '[2*(i+1)-3)' for i in range(3, 10)] est-elle bien parenthésée ?

Non. On lit les parenthèses dans l’ordre : [ ouvre, ( ouvre, ) ferme la parenthèse de (i+1). La parenthèse suivante, ) après -3, devrait fermer la dernière parenthèse ouverte non fermée, qui est [ : les types ne correspondent pas.

Commentaire : L’expression a pourtant autant de parenthèses ouvrantes (3) que de fermantes (3) : c’est l’idée de la partie A, et c’est aussi sa limite.

Partie A - Comptage

2. Fonction compte_ouvrante

def compte_ouvrante(txt):
    nb = 0
    for c in txt:
        if c == '(' or c == '[' or c == '{':
            nb = nb + 1
    return nb

Commentaire : On peut aussi écrire if c in '([{':.

3. Fonction compte_fermante

def compte_fermante(txt):
    nb = 0
    for c in txt:
        if c == ')' or c == ']' or c == '}':
            nb = nb + 1
    return nb

4. Fonction bon_compte

def bon_compte(txt):
    return compte_ouvrante(txt) == compte_fermante(txt)

5. Une chaîne qui trompe bon_compte

Par exemple ')(' : une ouvrante et une fermante, donc bon_compte renvoie True, mais la parenthèse est fermée avant d’être ouverte. De même '(]' : les types ne correspondent pas.

Commentaire : Le comptage ne vérifie ni l’ordre ni le type des parenthèses. L’expression de la question 1 est un autre exemple.

Partie B - Avec une pile

6. Méthodes empiler et depiler (lignes 9 et 14)

def empiler(self, elt):      # ligne 9
    self.contenu.append(elt)

def depiler(self):           # ligne 14
    if self.est_vide():
        return "La pile est vide."
    return self.contenu.pop()

Commentaire : Le sommet de la pile est la fin de la liste : append ajoute à la fin et pop() enlève et renvoie le dernier élément.

7. Nombre de comparaisons

Il faut se fixer une façon de compter. Ici, pour chaque caractère, on teste s’il est ouvrant (1 comparaison), puis, s’il ne l’est pas, s’il est fermant (1 comparaison). Pour chaque parenthèse fermante, depiler teste si la pile est vide (1 comparaison) et on vérifie que les deux parenthèses forment un couple (1 comparaison). À la fin, on teste si la pile est vide (1 comparaison).

Caractères de 'tab[2*(i+4)]-tab[3]' Nombre Comparaisons
Parenthèses ouvrantes 3 3×1=33 \times 1 = 33×1=3
Parenthèses fermantes 3 3×(2+2)=123 \times (2 + 2) = 123×(2+2)=12
Autres caractères 17 17×2=3417 \times 2 = 3417×2=34
Test final de la pile 1
Total (23 caractères) 50

Pour une chaîne de taille nnn, chaque caractère coûte au plus 4 comparaisons (une parenthèse fermante), plus le test final : au maximum 4n+14n + 14n+1 comparaisons. Le coût est linéaire en nnn.

Commentaire : Selon la façon d’écrire le test (par exemple c in "([{" compte pour 3 comparaisons), le nombre exact change, mais il reste proportionnel à nnn : c’est cela qu’il faut retenir.

8. Fonction est_bien_parenthesee

def est_bien_parenthesee(txt):
    couples = {")": "(", "]": "[", "}": "{"}
    p = Pile()
    for c in txt:
        if c in "([{":
            p.empiler(c)
        elif c in ")]}":
            if p.est_vide():
                return False
            if p.depiler() != couples[c]:
                return False
    return p.est_vide()

Commentaire : Il faut tester si la pile est vide avant de dépiler : sinon depiler renvoie la chaîne "La pile est vide.", qui n’est pas une parenthèse (le résultat serait juste, mais par chance). À la fin, la pile doit être vide : sinon une parenthèse ouvrante n’a jamais été fermée, comme dans "((".
