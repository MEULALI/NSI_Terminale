1. Fonction possible_avec_penalites_seules

def possible_avec_penalites_seules(score):
    if score == 0:
        return True
    if score < 0:
        return False
    return possible_avec_penalites_seules(score - 3)

Commentaire : Un score est possible avec des pénalités seules si et seulement si c’est un multiple de 3. On peut aussi écrire return score % 3 == 0.

5. Fonction nb_solutions

def nb_solutions(score):
    if score <= 6:
        return [1, 0, 0, 1, 0, 1, 1][score]
    return nb_solutions(score - 3) + nb_solutions(score - 5) + nb_solutions(score - 7)

Commentaire : On peut aussi écrire les sept cas de base avec des if.
Vérification : nb_solutions(11) = 3 et nb_solutions(13) = 6.

8. Fonction solutions_possibles

def solutions_possibles(score):
    if score < 0:
        resultat = []
    elif score == 0:
        resultat = [[0]]
    else:
        resultat = []
        for coup in [3, 5, 7]:
            liste = solutions_possibles(score - coup)
            for solution in liste:
                solution.append(score)
                resultat.append(solution)
    return resultat

Commentaire : Dans l’énoncé, resultat.append(...) était aligné avec for solution, donc en dehors de cette boucle : on ne pourrait ajouter qu’une seule solution par coup. Il faut l’indenter dans la boucle (comme ci-dessus), ou écrire resultat.extend(liste). Il manquait aussi la ligne def solutions_possibles(score):.
Vérification : solutions_possibles(8) renvoie [[0, 5, 8], [0, 3, 8]].

Commentaire global : L’énoncé ne comporte qu’une partie A, il n’y a pas de partie B.
